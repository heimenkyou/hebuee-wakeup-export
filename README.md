# 河北环境工程学院课表 → WakeUp CSV

从学校 WebVPN 进入教务系统，抓取当前课表，生成 WakeUp 课程表可以直接导入的 CSV。

只适用于河北环境工程学院（WebVPN + 正方教务）。其他学校需要修改 `main.py` 里的入口地址和课表接口。

## 使用

1. 双击 `run.bat`。
2. 首次运行会在项目目录创建 `.venv` 并安装 `playwright`，只需联网一次。
3. 浏览器打开 `https://webvpn.hebuee.edu.cn/` 后，登录统一身份认证。
4. 进入教务系统，打开「个人课表查询」，选好学期，等课程显示出来。
5. 回到终端窗口按回车。
6. CSV 生成在 `output\`，脚本会自动打开该文件夹。

把 CSV 发到手机，在 WakeUp 里选择「从 Excel 导入」。

需要 Python 3.10+ 和 Edge。依赖只装在 `.venv`，不影响系统 Python。

## 学期和输出

脚本读取课表页面当前选中的学年、学期。页面默认就是当前学期；要导其他学期，先在页面上切换，再按回车。

页面读不到学期时按当前日期推测，也可以手动指定：

```bat
python main.py --term 2025 12
```

`3` 第一学期，`12` 第二学期，`16` 短学期。

CSV 列为：课程名称、星期、开始节数、结束节数、老师、地点、周数。周次会转成 `1-5、7-11单、12-16双` 这种写法。教室默认精简掉校区前缀，保留完整名称用 `--no-shorten-room`。

## 注意事项

- 脚本不读取账号密码。登录、验证码、扫码都在浏览器里手动完成。
- 登录 Cookie 存在 `.auth/`，课表存在 `output/`，两者都已加入 `.gitignore`，不会被提交。
- 数据只在本机处理，不上传服务器。
- 学校改版后脚本可能失效。抓不到数据时，看 F12 → Network 里返回课表的那条请求。

## 实现

Playwright 驱动本机 Edge。用户按回车后，脚本从当前所有标签页和 iframe 里找课表数据：先读页面内嵌变量，再读监听到的网络响应，最后尝试正方课表接口。解析后按 WakeUp 模板写 CSV。
